# Google Maps is not a source dataset

No Google Maps listing names, addresses, coordinates, imagery or road geometry were copied into this project. No Google Maps validation claim is made. The small identity-check sample uses the official sources linked in its review table; map geometry comes from reusable OSM-derived data. See [Google Maps end-user terms](https://maps.google.com/help/terms_maps/) and [Maps Platform terms](https://cloud.google.com/maps-platform/terms).
